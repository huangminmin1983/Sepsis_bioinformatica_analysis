# 脚本用途

- **`main.R`**：单细胞 RNA 测序数据质控、标准化、Harmony 批次效应校正、降维聚类、差异表达分析与细胞类型注释。
- **`cell.R`**：使用 CellChat 推断细胞间通讯关系，并可视化配体–受体相互作用、信号通路及通讯网络。
- **`monocle_main.R`**：使用 Monocle 2 进行细胞拟时序和轨迹分析，研究基因表达随拟时序的变化。
- **`scTenifoldKnk.R`**：使用 scTenifoldKnk 对目标细胞群中的候选基因进行虚拟敲除，分析基因调控网络扰动及其显著受影响基因。
- **`tf.R`**：使用 DoRothEA 和 VIPER 推断转录因子活性，比较不同细胞类型的活性模式并绘制热图。
